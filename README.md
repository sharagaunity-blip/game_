# Отчет о работе с нейросетью (PROMPTS.md)

## Кейс 1: Нарушение инкапсуляции в сгенерированном коде
* **Промпт:** «Напиши класс игрока и врага на JS для игры на Canvas».
* **Проблема в ответе ИИ:** Нейросеть создала публичные свойства `this.health = 100` и в цикле проверки столкновений напрямую уменьшала их: `player.health -= enemy.damage`. Это нарушает требование инкапсуляции.
* **Решение:** Переписал поля на приватные (`#health`, `#coffeeLevel`), добавил геттеры и метод `takeDamage()`, который сам контролирует логику уменьшения здоровья и щита.

## Кейс 2: Устаревший игровой цикл и утечка кадров при рестарте
* **Промпт:** «Сделай игровой цикл и кнопку перезапуска игры после проигрыша».
* **Проблема в ответе ИИ:** ИИ использовала `setInterval(update, 1000/60)`, а при нажатии на кнопку рестарта запускала новый интервал поверх старого, из-за чего игра ускорялась в 2 раза.
* **Решение:** Заменил `setInterval` на современный `requestAnimationFrame` со стрелочной функцией и добавил флаг `#isGameOver`, который корректно останавливает старый цикл перед запуском нового.

## Кейс 3: Слишком быстрое движение по диагонали
* **Промпт:** «Добавь управление персонажем на WASD и стрелки».
* **Проблема в ответе ИИ:** При одновременном нажатии `W` и `D` координаты `x` и `y` изменялись на полную скорость, из-за чего по диагонали студент двигался в 1.41 раза быстрее, чем по прямой.
* **Решение:** Добавил проверку `if (dx !== 0 && dy !== 0)` и умножил векторы движения на `Math.SQRT1_2` для нормализации скорости.
